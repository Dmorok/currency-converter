# ₴ Конвертер валют

Швидкий мінімалістичний конвертер валют для Chrome. Вводиш суму один раз і бачиш її в усіх своїх валютах — за ринковим курсом або за офіційним курсом НБУ.

[English](README.md) · **Українська**

![Конвертер валют: світла й темна тема, український інтерфейс і налаштування](docs/screenshots/hero.png)

## Можливості

- **Одна велика сума — багато валют.** Клікни по будь-якому рядку, щоб зробити його валюту основною.
- **Два джерела курсу.**
  - *Ринковий*: агрегований середній курс, оновлюється кожні 5 хвилин.
  - *НБУ*: офіційний курс Національного банку, встановлюється раз на робочий день.
- **Математика прямо в полі:** `250*3+40`, `1200/4`, `1.5k`, `2m`. Працюють і `1 234,50`, і `1,234.50`.
- **Комісія.** Можна додати комісію картки (наприклад `+2%`) до всіх перерахованих сум.
- **60+ валют**, серед них криптовалюти (BTC, ETH, USDT) і метали (XAU, XAG). Пошук за кодом або назвою.
- **Перетягування рядків** і меню ⋮: зробити основною, домашньою, скопіювати суму, підняти вгору, видалити.
- **Копіювати все** — усі суми одним кліком.
- **Світла й темна тема** (за замовчуванням — як у системі).
- **Інтерфейс англійською та українською**, перемикається в налаштуваннях. Назви валют теж перекладені.
- **Працює офлайн** на останніх збережених курсах. Шрифти й прапори вбудовані, нічого не вантажиться ззовні.
- **Зручно з клавіатури**
  - <kbd>Alt</kbd>+<kbd>W</kbd> відкриває вікно
  - почни набирати цифри будь-де, і вони потраплять у поле суми
  - <kbd>Alt</kbd>+<kbd>↑</kbd>/<kbd>↓</kbd> змінює основну валюту
  - <kbd>Esc</kbd> закриває панелі

## Встановлення

### З релізу (рекомендовано)

1. Завантаж останній `currency-converter-vX.Y.Z.zip` з [Releases](../../releases) і розпакуй.
2. Відкрий `chrome://extensions` і ввімкни **Режим розробника**.
3. Натисни **Завантажити розпаковане** і вибери розпаковану папку.

### З вихідного коду

```bash
git clone <посилання-на-репозиторій>
```

Потім у `chrome://extensions` натисни **Завантажити розпаковане** і вибери папку. Збирати нічого не треба: це звичайні HTML, CSS і JS.

Працює в Chrome, Edge, Brave, Opera, Vivaldi та інших браузерах на Chromium (Manifest V3).

## Джерела курсів

| Джерело | Ендпоінт | Оновлення |
|---|---|---|
| Ринковий (основне) | `cdn.moneyconvert.net/api/latest.json` | ~5 хв |
| Ринковий (запасне 1) | [fawazahmed0/exchange-api](https://github.com/fawazahmed0/exchange-api) через jsDelivr / Cloudflare | щодня |
| Ринковий (запасне 2) | [open.er-api.com](https://www.exchangerate-api.com/docs/free) | щодня |
| НБУ | [bank.gov.ua](https://bank.gov.ua/ua/open-data/api-dev) | робочі дні |

Курси наведено для довідки. Перед реальною операцією уточнюй курс у своєму банку.

## Приватність

Жодної аналітики, трекінгу чи акаунтів. Розширення звертається лише до ендпоінтів курсів, перелічених вище. Список валют і налаштування зберігаються в `chrome.storage.local` на твоєму пристрої. Детальніше: [PRIVACY.md](PRIVACY.md).

## Збірка релізу

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

Скрипт створює `dist/currency-converter-v<версія>.zip`, у якому лише потрібні розширенню файли.
